📸 Photo Memory Booth

An interactive web application that allows users to upload personal photos, add custom memory quotes, and flip cards to reveal or edit those memories. Designed with simplicity and sentimentality in mind, this app runs on Node.js and Express with a JavaScript frontend.

🚀 Features

🖼️ Upload personal photos

💬 Annotate photos with custom quotes

🔄 Flip photo cards (click to show memory, double-click to flip back)

💾 Memories saved in the browser using localStorage
